# ppt-concepts-pagegen

把"一整章的每一个 x.x 二级小节"各生成一张 **节首「动笔划课本」页**（SVG），版式全章统一。对应 `ppt-course-builder` 六步流水线的**步骤 2**：本章有几个 `x.x` 就至少几张、不省略。

> 本 skill 只负责**生成 SVG**。转 PNG（sharp）与插入 PPT 归 `ppt-diagram-maker`（唯一 SVG→sharp→pptx 路径），装配顺序由 `ppt-course-builder` 六步统一调度，不在本 skill 内。

## 铁律（照做，别自创）

1. **每一条课本原句都必须能在课本上一字定位**——逐页读 `0_textbook_code/{章}/textbook/` 扫描页图**照抄**，🔴严禁意译 / 改写 / 换同义词（用法是"老师指哪句、学生就划哪句"，措辞不一致学生就划不了）。
2. **每条原句前用醒目色标出它在本地第 5 版扫描件里的印刷页码 `P<页>`**（供学生照页码翻书再划句）。页码一律取自 `0_textbook_code/教材目录映射.md` / 扫描件，逐句核对、不臆造。定位原文先查映射表，不凭记忆猜章号页码。
3. **全页统一用「划」不用「圈」**：角标「📖 动笔划课本 · §X.Y」、引导语"把下面这些【原句】用笔**划**出来"。
4. **每页 ≤6~7 条原句**保投影可读；某节概念密、一页装不下就**拆成多张**，文件名加后缀 `_2`/`_3`（如 `3.2concepts.svg` / `3.2concepts_2.svg`）。
5. **页脚三合一提示带**：【重点】【难点】【易错易混】。**不再写**"⏱ 数到 N 抬头"计时口令（留多久教师当堂自主）。
6. 中文一律 **Microsoft YaHei**；无新概念的小节也照样出一张，正文写"本节无新增术语"。

## 版式（脚本已内置，改动前先核对投影可读）

- 画布 `1280×960`（4:3）；标题条 `#2B6CB0`、主体深蓝 `#1A365D`、页码高亮 `#FBD38D`、易错带 `#FEB2B2`。
- 原句字号 21 / 行高 30 / 句间距 15；按**像素预算**自动换行，行首不出现收尾标点。

## 用法

1. 照着 `scripts/gen_concepts.py` 顶部的 `SECTIONS` 数据结构，填本章各小节：

   ```python
   # (节号, 节标题, [(扫描件页码, 课本原句), ...], (重点, 难点, 易错易混))
   SECTIONS = [
     ("4.1", "选择结构和条件判断", [
       ("83", "这就是选择结构要解决的问题。"),   # ← 必须是课本原句、且 83 是核对过的扫描件页码
       ("83", "用 if 语句进行检查……（图 4.2）"),
     ], ("先判断条件、再决定走哪条路", "\"条件\"用表达式表示", "if(x>=0) 后面不能加分号")),
     # … 本章每个 x.x 都列一项
   ]
   ```

2. 在本章 `slides/` 目录下运行脚本（脚本会把 `SECTIONS` 写进同目录的 `{节号}concepts.svg`）：

   ```
   python scripts/gen_concepts.py --data <本章数据.py 或内联 SECTIONS> --out <{章}/slides>
   ```

   最省事的用法：把 `scripts/gen_concepts.py` 复制到本章 `slides/` 下，直接改文件顶部的 `SECTIONS` 再 `python gen_concepts.py`。

3. 生成后 **PNG 产出须读回验证中文没变豆腐块**（sharp 转图环节，见 `ppt-diagram-maker`）。

## 脚本

- `scripts/gen_concepts.py`：版式引擎（照搬自 `_gen_concepts0X.py`，逐章验证过）。顶部 `SECTIONS` 是唯一每章要改的地方；`cw/px/wrap/build` 为通用排版，不轻易动。

## 收工自查

- [ ] 本章每个 `x.x` 都至少有一张 `{节号}concepts.svg`（无新概念的小节也留一张写"本节无新增术语"）。
- [ ] 每条原句都能在课本一字定位、每条都带核对过的 `P<页>`。
- [ ] 全页用「划」不用「圈」；页脚是【重点】【难点】【易错易混】、无计时口令。
- [ ] 每页 ≤6~7 条，超了拆 `_2`/`_3`。

## 已知坑

- 首行换行预算太小会把句子切得怪异 → 脚本统一用 `(XMAX-X0)-pfx_w` 重切一次，勿删这段。
- 页码是**第 5 版扫描件**的印刷页（与某些 `P` 前缀混淆）；学生纸质若是别的版次页码对不上，属正常，只用 §号/图号/例号口头定位。

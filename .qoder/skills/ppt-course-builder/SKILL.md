# PPT Course Builder（整章课件装配流水线）

把**一整章教材**变成**一条能上课的 PPT + 一份提词本**。与 `ppt-diagram-maker`（只画单张图）、`textbook-code-extractor`（只提取可编译代码）分工：**本技能管"整章的装配顺序与固定套路"**——先做什么后做什么、每节长什么样。

## 先判交付方式（章有没有现成 PPT）
- **已有官方配套 PPT**（如谭浩强第 2 章版）：**不重建**。在现有文件上**插入"节首·划概念页" + 隐藏/删除冗余页**，只保留一条主线。官方图里的流程图/N-S/代码图质量高，重画又贵又易错。
- **新章、无现成 PPT**（第 3 章起）：从头按下面六步搭。

## 课时约定（每次课 = 90 分钟，如 8:30–10:00）
章定位（步骤 0）时一并写定本章几次课，备课导航据此排节奏表：
- **技能章默认两次课**：第 3～9 章全部是技能章（顺序/选择/循环/数组/函数/**指针**/结构体），内容多、要留随堂练，一次 90 分钟塞不下全部重点。
- **认知章 / 入门章一次课**：第 1～2 章（只建观念、不教新语法）。
- **以本章“重点分级页数 + 例题量”为准微调**：重章（循环、函数、**指针**）第二次课可能仍紧，允许占第三次；轻节可合并。默认值是“技能章两次”，不是死规矩。

## 六步流水线（顺序就是红线：提词本永远最后）

```
0. 章定位：认知章 / 技能章 → 决定页数、节奏与课时数（每次课 = 90 分钟）
1. 拉节骨架：列出本章每个 x.x 二级标题，各标【必讲透/重点练/会认/带过】 → 产 `第N章备课导航.md`
2. 每个 x.x 二级标题至少配 1 张「节首·划概念」先行页（有几个至少几张、宁空勿缺；概念密的节按【考点】逐条列全、一页装不下就拆多张；版式全章统一，模板见下；🔴生成器见技能 `ppt-concepts-pagegen`）
3. 填主线页（升级链/例题/源码）；重复页与课后参考页先【隐藏】
4. 定稿放映顺序 → 跑脚本校验可见页序（勿拿文件名当顺序）；🔴再跑 `scripts/check_no_leak.py --depth 2`，确认无“🔴抢答案”命中；有备份时定稿后可删隐藏页
5. 按定稿放映顺序，逐张写提词本（提词 + 口播；口吻必须“不装腔、不报幕、要真互动、不卖关子、一语点破天机”，见下方口播红线）
6. 备注回写（必作）：跑 `scripts/sync_notes.py` 把口播稿逐张写进 PPT「演讲者备注」；🔴**三处同步**——口播稿 / PPT 备注 / 提词本必须当次一起改完（见铁律二）
```

🔴 **铁律一**：**先定 PPT（步骤 0–4），提词本（步骤 5）永远最后写**，且必须在第 4 步校验过放映顺序之后。**幻灯片结构一变（挪页/加页/删页），提词本就整本作废**——这是踩过的坑，别再反过来。

🔴 **铁律二（三处同步）**：同一份“要老师张嘴念”的话有**三个落点**，改动必须**当次一起改完三处**，不得只做一处：
**① 口播稿 `第N章_口播稿.md`（唯一事实源）→ ② PPT 演讲者备注（跑 `scripts/sync_notes.py` 生成，绝不手工改）→ ③ 提词本 `第N章_提词本.md` 对应页的【口播】/【提词】（手工同步）**。
收工前自检：**重跑 dry-run 显示「需写入 0 页」** + **提词本改过的页与口播稿同一口径**。备注与备课稿不一致，老师上台看演示者视图就会穿帮。

## 「节首·划概念页」固定版式

> 本节版式的**权威生成器与铁律在技能 `ppt-concepts-pagegen`**（装配步骤 2 调它出 `{节号}concepts.svg`）；此处模板仅作总览，两处若不一致以 `ppt-concepts-pagegen` + 作用域规则 `ppt-diagram.md`（课件图与整章装配红线）为准。

一页对应一个 x.x 节，作为该节的开场，让学生**先在课本上划画再听讲**：

```
📖 动笔划课本 · §X.Y  <节标题>            ← 固定角标+节号+节标题（每页一样）
──────────────────────────────────
翻到课本 §X.Y，把下面这些【原句】用笔划出来（P 为课本页码）：     ← 固定引导语
   · P<页> <课本原句1>（照抄、禁意译；P 页码取自第 5 版扫描件 / `教材目录映射.md`，逐句核对不臆造）
   · P<页> <课本原句2>
   · P<页> <课本原句3>（概念密的节按【考点】逐条列全、不止三句；每页 ≤6~7 条，一页装不下就拆 `_2`/`_3`）
   ·（本节若无新概念，就写“本节无新增术语，跟着老师看例题”）
──────────────────────────────────
【重点】<一句话>　【难点】<一句话>　【易错易混】<一句话>   ← 固定页脚（三合一提示带）
```

要点：
- **除「节首·动笔划课本页」外任何产出绝不写课本页码**——学生版次（如第 6 版）与本地核对用的扫描件版次（第 5 版）页码不同，其余一律只用 §号/图号/例号定位。🔴**唯一例外**：本页「节首·动笔划课本页」**每一条课本原句前用醒目色标出它在本地第 5 版扫描件里的印刷页码 `P<页>`**（如 `P99 switch 语句是多分支选择语句。`），供学生照页码翻到那页再划句——页码一律取自 `教材目录映射.md`/扫描件、逐句核对不臆造，且只写第 5 版扫描件页码（本版更新：旧模板此处不写页码，现改为每条带 P 页码）。
- 🔴**清单每一条都必须是课本上可一字定位的原文（照抄）**，严禁意译/改写/换同义词——因为用法是“老师指哪句、学生在书上划哪句”，措辞不一致就划不了。术语/人名/年份/例号先查 `0_textbook_code/教材目录映射.md` 定位图片路径，再读对应 `textbook/` 扫描页图取原句，**不凭印象、不拿“已核对的备课导航”的转述代替原文**（一切以课本为主）。
- 认知章没有代码可跑，这页就是学生手上的"注意力锚"，也为后续问答、复习留下纸质重点。
- **二级标题有几个就至少生成几张、不省略；🔴概念密的硬核节以【考点】为单位逐条列全（凡重要/需记忆/易考点一律列为一条课本原句、不封顶，不是每小节只划一句），一页装不下就拆成多张（每页 ≤6~7 条原句保投影可读），该清单同时兼作学生课后复习清单**；某节没有新概念，也照样保留一张、只写“本节无新增术语，跟着老师看例题”。
- **版式必须全章统一**：固定角标“📖 动笔划课本 · §X.Y”+ 固定引导语“翻到课本 §X.Y，把下面这些【原句】用笔划出来（P 为课本页码）”+ 每条原句前带 P 页码 + 固定页脚【重点】【难点】【易错易混】三合一提示带（🔴取消旧“⏱ 数到 N 抬头”计时口令），让学生一看这页就条件反射该动笔划书。
- 🔴**“往后每一节都这么做”这个仪式，只在本章第一张划概念页上讲一句**（“从这张起，每节开头都有这么一页，动作固定…”）；**上一张正文/地图页不得提前宣布**（一页只讲一页的事，见 `lecture-script.md` ④b）。

## 放映顺序校验（PowerShell 解 .pptx）

`.pptx` 是 zip。**真实放映顺序在 `ppt/presentation.xml` 的 `<p:sldIdLst>`**（按 `r:id` 经 `ppt/_rels/presentation.xml.rels` 解析到 `slides/slideN.xml`），**不是文件名顺序**。可见性看每页根 `<p:sld>` 的 `show="0"`（=隐藏）。正文文本用 `[regex]::Matches($xml,'<a:t>(.*?)</a:t>')` 抽取。

- Windows PowerShell 5.1 会按 ANSI 读中文路径脚本导致崩溃 → 一律用 **pwsh 7**。
- 单引号字符串里要表示撇号用 `"'"`（三个单引号是未闭合字符串）。
- 校验脚本与导出文件都是**临时**的，用完即删，别留在仓库。

## 备注回写（口播稿 → PPT 演讲者备注）

脚本：`scripts/sync_notes.py`（依赖 `pip install python-pptx`，Python 3.14 可直接装）。

```powershell
cd 0_textbook_code\{章}          # 不带参数会自动找「*口播稿*.md + 最大的 *.pptx」
python <技能目录>\scripts\sync_notes.py            # dry-run：逐页打印 KEEP/WRITE
cd 0_textbook_code\{章}; python <技能目录>\scripts\sync_notes.py --apply   # 先备份再写
```

- 🔴**映射只认放映可见序**：`prs.slides` 的顺序就是 `presentation.xml` 的 `<p:sldIdLst>`（= 放映序），跳过根元素 `show="0"` 的隐藏页后，第 k 张 == 稿里的「🗂 第 k 张」。**不拿文件名、不拿编辑视图页码当序号**（那是含隐藏页的绝对索引，必然错位）。
- **页数不等就中止**：可见页数 ≠ 稿段数，说明稿还没跟上课件结构——回到第 4 步重定稿再写稿，不要硬写。
- **KEEP/WRITE 差量 + 幂等**：页头沿用「▶ 第 N 张 · 标题」旧格式，没改动的页显示 KEEP 不动；`--apply` 后**重跑一次 dry-run 应看到「需写入 0 页」**，才算生效。
- 🔴**只改备注不够，必须三处同步**：本次改动涉及的每一页，都要同时出现在口播稿（事实源）、PPT 备注（脚本生成）、提词本（手工改）三处；只改 PPT 不改稿子、或只改稿子不重跑脚本，都算没改完（提词本落后就是第 2 章踩过的坑）。
- 只写 `notes_slide.notes_text_frame.text`，**不碰版式、图与页序**；备注里的 markdown（`**`、代码围栏）已洗成纯文本，否则备注栏全是星号噪声。
- Windows 控制台默认 GBK，脚本里已 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`，不然“▶ / 🗂”这类符号会直接 UnicodeEncodeError。

## 跳页泄露扫描 `scripts/check_no_leak.py`（写完每页、定稿前必跑）

把“一页只讲一页”从人的主观判断变成机器可查：**拿下一页（`--depth 2` 可看下两页）标题里的结论词回搜本页**，命中就列出。

```powershell
cd 0_textbook_code\{章}
python <技能目录>\scripts\check_no_leak.py --depth 2   # 退出码 0 = 无🔴抢答案
```

输出分两档，正好对应三分法：
- 🔴 **陈述句里说出下页结论词 = 抢答案**→ 必须删，或改成不含结论词的问句（退出码 1）；
- 🟡 问句里提到 = 留问不留答的过渡，通常合规。

误报（合法命中）怎么压：① 稿首加一行 `> **泄漏白名单**：词、词`（稿首不属于任何一页正文，`sync_notes.py` 不会把它写进备注）；② 临时 `--allow 词,词`；③ 标题含“划概念页 / 地图 / 主线 / 升级链 / 总结 / 收束 / 参考”的**总览页自动跳过**（这些页本来就要提前目录）；稿首“> **主线**：…”行里的题（如“求 5!”）也自动当允许词。

它能拓出的典型错（第 2 章均真实发生过）：讲“选择”那页写“第三种能把一段活反复干很多遍，它就是循环，还分两种”；讲三种结构那页写“于是有人一狠心，把箭头全砍了”；地图页预告“往后每节开头都有的固定动作是翻课本圈原句”。

## 存放与命名
- 📌 **全章目录与图片映射（权威参考，第 5 版）**：`0_textbook_code/教材目录映射.md`——完整三级目录 + 印刷页码 + 对应 JPG 路径，任何需要定位课本内容的步骤先查此文件。
- 🔴**版次口径**：学生纸质书为第 6 版（无电子版），**一切装配以第 5 版扫描件/映射文件为准**（节数、节名、例号都按第 5 版）。官方课件目录页若与正文节号不一致（如第 3 章目录 4 节、正文 5 节），那是课件自身残留错误，以正文（=第 5 版）为准，不据此怀疑装配做错了版次。
- 节骨架 / 备课导航：`0_textbook_code/{章}/第N章备课导航.md`
- 节首划概念页内容（定"大体内容"用）：`0_textbook_code/{章}/slides/节首划概念页.md`；正式成图走 `ppt-diagram-maker` 的**唯一路径：手写 SVG→sharp 转 PNG→用 python-pptx 直插 PPT**（🔴不再转 `.puml`、不走豆包）。
- 🔴**节首划概念页课件图命名固定为 `{节号}concepts.svg`**（去掉 §、保留 x.y 小节号）：§2.3 → `2.3concepts.svg`、§2.5 → `2.5concepts.svg`，sharp 转同名 `.png` 后直插 PPT，一律存 `0_textbook_code/{章}/slides/`；**一节按考点拆多张时按序加后缀 `_2`/`_3`（如 §3.2 → `3.2concepts.svg`/`3.2concepts_2.svg`/`3.2concepts_3.svg`）**。文件名与"每二级标题一张"一一对应，师生凭文件名即知是哪节的划概念页；其余主线图（升级链 / 收束 / 课后参考等）仍用中文语义名。
- 提词本：`0_textbook_code/{章}/第N章_提词本.md`，编号 = 放映可见顺序（跳过隐藏页）。
- 口播底稿（备注回写的唯一事实源）：`0_textbook_code/{章}/第N章_口播稿.md`，段标题固定写成 `### 🗂 第 N 张 · <标题>【约 X 分钟】`，脚本靠这行对页；🔴**稿首必写一行「时间盘」**（几点到几点、课间在第几张之后、第一节到第几张），全稿的“今天 / 刚才 / 下节课”一律以它为准。
- `slides/` 不在 .gitignore（老师原创课件，正常入库）。**"课本全弄完才 commit"，不主动提交 Git。**

## 质量红线（与常驻规则 `core-role.md` 及各作用域规则一致）
- 一切以课本为主：例号 / 直到型·当型 / 人名年份 / 定义原句必核对。
- 学生视角、去教师腔：划概念页给学生看，**不写**"老师照着讲"类 meta。
- 投影零小字：正文 ≥ 16、理想 ≥ 18，概念清单字号别缩；思路/导引上屏，只有口播细节进备注。
- 🔴**时间口径与进度承诺必真实**（写每页时自查“今天 / 刚才 / 下节课”三个词）：“今天/这节课”=本大节全程（含课间）；**课间回场只说“刚才/第一小节”，绝不说“上节课”**（那是另一天）；“下节课”只指下一次上课。凡“我要抽查、你们就用这句答我”类承诺，必须能落到稿中已排定的位置（哪张随堂题/哪个收尾），不得许诺到一个不存在的时间点（第 2 章就写出过“§2.2 划概念页说‘下节课问算法怎么定义’”，可那定义下一张就讲、本小节内就有随堂题）。详见 `lecture-script.md` ⑥。
- 🔴**一页只讲一页 + 多回看少前瞻**：写完每页跑 `scripts/check_no_leak.py --depth 2`（🔴＝陈述句里说出下页结论词＝抢答案，必删）；同时逐张确认“回看钩子”：指向难点/易错点/旧例题，**不重复已讲透的简单点**、不超 2~3 句。
- 提词本**最后写**、且**校验放映顺序后**写。
- 🔴**口播/提词本的说话口吻——“三不一破”**：写第 5 步提词本与整章口播稿时守**①不装腔**（开门见山、删自我加戏铺垫）、**②不报幕**（不说“我给你举个例子/我考两个问题/接下来看”，要举例直接“比如…”）、**③别独角戏**（每 3~4 句交还学生，且抛的必须是学生此刻答得出的真问题）、**④不卖关子**（禁说书腔/禁把答案赊出去，章标题大词开场即点破；④b 一页只讲一页、靠 `check_no_leak.py` 机器校验；④c 多回看少前瞻）、**⑤一语点破天机**（每张须有一句“学生自己搜不到”的话，先点破再让学生验证）。**完整 ①~⑥ 表述、禁语清单与质检清单以作用域规则 `lecture-script.md` 为唯一权威**，本处不复制，若与它不一致以 `lecture-script.md` 为准。

## 工作流清单（复制跟踪进度）

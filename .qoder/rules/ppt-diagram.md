# 课件图与整章装配规范

## 课件图：一律学生视角、看图知意（红线）

为课件/PPT 生成任何图时，图上文字**只给学生看**：

1. **严禁**出现"教学说明/备注/注/老师照着讲"这类教师腔 meta 标题或旁注。
2. 解释文字要让**只看图的学生**读懂"在讲什么、为什么"；讨论时的口语（如"少了一个"）**不得直接上屏**，须按课本把"到底少了哪一格、为什么不能省"讲清楚。
3. 涉及教材事实（例号、直到型/当型、人名年份）**必核对**本地 `0_textbook_code/{章}/textbook/` 扫描页图，不凭印象。**除「动笔划课本页」每条原句前标第 5 版扫描件页码 `P<页>`（唯一例外）外，课件/图上不得出现任何课本页码**（学生版次与扫描件页码对不上），其余只用 §号/图号/例号定位。
4. **投影素养·学生可见文字零小字 + 思路必须上屏**：投影仪本就发虚，凡呈现在学生面前的字一律要大（正文等效 ≥18pt、绝对下限 ≥16pt），放不下就精简措辞或放大画布、**绝不缩字硬塞**；**每页除图/骨架外必须有"思路线/导引问题/关键解释"上屏**（否则满屏并列名词、学生像没头苍蝇）。导引问题不得当钩子使，要学生此刻答得出（见 `lecture-script.md`）。只有老师口播的详细展开才放 PPT"演讲者备注"。
5. **要像 PPT 课件、不像零散流程图**：4:3、标题居顶、主体居中、大留白、圆角柔和；元素放不下就分行/分组/放大画布，字号是底线。
6. 中文用微软雅黑，PNG 产出后须读回验证中文没变豆腐块。

**工具链（唯一默认）**：手写 SVG → sharp 转 PNG → python-pptx 直插 PPT。🔴旧的 `.puml` 底稿喂豆包已弃用。完整流程见技能 `ppt-diagram-maker`；课件图存 `0_textbook_code/{章}/slides/`（不在 gitignore 内，正常入库）。🔴节首「动笔划课本」`{节号}concepts` 页**不走本技能**，走 `ppt-concepts-pagegen`。

## 整章课件装配：六步流水线（红线）

把"一整章教材"装配成一节课件 + 提词本，走固定套路（完整流程见技能 `ppt-course-builder`）：

**0 章定位（认知/技能）→ 1 拉 x.x 节骨架并标【必讲透/重点练/会认/带过】→ 2 每个 x.x 二级标题至少插一张「节首·划概念」先行页 → 3 填升级链/例题/源码主线页、冗余页先隐藏 → 4 跑脚本校验放映可见顺序后定稿 → 5 逐张写提词本。**

- **提词本永远最后写**，且必须在**校验过放映顺序之后**——幻灯片结构一变（挪/加/删页），提词本整本作废。
- **有官方配套 PPT 的章不重建**（在其上插页 + 隐藏/删除冗余），**新章才从头搭**。
- 第 2 步「划概念页」要求：本章有几个 x.x 就至少几张、不省略；**概念密的硬核节以【考点】为单位逐条列全**（凡重要/需记忆/易考点一律列为一条课本原句、不封顶），一页装不下就拆多张（每页 ≤6~7 条原句保投影可读），该清单兼作学生课后复习清单；某节无新概念也留一张只写"本节无新增术语"，版式全章统一。
- **每条必须是课本上可一字定位的原文**（逐页读 `textbook/` 扫描页图照抄），**严禁意译/改写/换同义词**（用法是"老师指哪句、学生就划哪句"）。

**划概念页版式三要素**：
- 固定角标 **"📖 动笔划课本 · §X.Y"**（🔴一律用「划」不用「圈」）。
- 引导语"翻到课本 §X.Y，把下面这些【原句】用笔**划**出来"；**每一条课本原句前用醒目色标第 5 版扫描件印刷页码 `P<页>`**（如 `P99 switch 语句是多分支选择语句。`），页码取自 `教材目录映射.md`/扫描件、逐句核对不臆造——这是"不写页码"的**唯一例外**。
- 页脚改为 **重点 / 难点 / 易错易混** 三合一提示带（🔴取消"⏱ 数到 N 抬头"计时口令，划句留多久由教师当堂决定）。

**存放与命名**：划概念页内容存 `0_textbook_code/{章}/slides/节首划概念页.md`；SVG 版式与铁律固化在技能 `ppt-concepts-pagegen`（本条与技能不一致以本条为准）；课件图按节命名 `{节号}concepts.svg`（去 §、保 x.y，如 §2.3→`2.3concepts.svg`；sharp 转同名 `.png` 后 python-pptx 直插；🔴不再产 `.puml`、不走豆包；一节按考点拆多张时按序加后缀 `_2`/`_3`）。

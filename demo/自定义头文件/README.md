# 自定义头文件 demo

教你**自己写一个头文件(`.h`)**,并在 `main.c` 里用它。

## 文件

```text
自定义头文件/
├── max.h    # 自定义头文件:里面直接放 max 函数的"定义"(带函数体)
└── main.c   # 主程序:#include "max.h" 后调用 max
```

## 核心概念

- **`#include "max.h"` 干了什么**:预处理器把 `max.h` 的**全部内容原样复制**到这一行。
  所以 `main.c` 编译时,就等于把 `max` 的函数体"贴"了进来。
- **头文件能放定义吗**:能。本 demo 就把 `max` 的**定义**放在 `max.h`。
  前提是**同一个 `.h` 只被一个 `.c` 包含一次**,否则会出现"重复定义"链接错误。
  (更工程化的做法是"头文件放声明、`.c` 放定义",见 `../multifile_demo/`。)
- **头文件卫士**:`max.h` 首尾的 `#ifndef MAX_H / #define MAX_H / #endif`,
  防止同一个头文件被重复包含。
- **`"max.h"` vs `<stdio.h>`**:自己写的头文件用**双引号**;系统头文件用**尖括号**。

## 怎么运行

本 demo 只有 `main.c` 一个编译单元(`max.h` 是被包含进去的),所以**可以直接用运行箭头 ▷ / F5**:

```bash
gcc -std=gnu17 -Wall -g main.c -o main
./main
```

输出:

```text
x = 8, y = 13
max(x, y) = 13
```

## 动手练一练

1. 在 `max.h` 里再加一个 `int min(int a, int b)`(返回较小值);
2. 在 `main.c` 里调用并打印 `min(x, y)`;
3. 重新运行,看结果对不对。

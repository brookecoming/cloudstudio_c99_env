## 关键锚点（背这几个就塌不了）
- **5! = 120**；例 2.18 里 `i<=5` 变假 → 跳出循环执行 `printf`。
- **三种结构 → C 语法**：顺序=语句、选择=`if`、循环=`while`/`for`/`do-while`。
- **当型 vs 直到型**：先**问**后做＝当型(while)；先**做**后问＝直到型(do-while)。
- **有穷性**最怕的死循环；**有效性**是选择题最爱抠的那条。
- 年份人名：**Bohra & Jacopini 1966**（三结构）、**Nassi & Shneiderman 1973**（N-S 图）。
- 四道随堂题答案：**① B　② 递推法　③ 杜绝无条件转移　④ 顺序·选择·循环**。

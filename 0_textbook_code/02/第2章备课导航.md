## 一、重点分级（按课本节号顺序，★ 越多越要花时间）

> 开课第一句：**"这章看着节多，其实真正要花时间的是打★的几行；自然语言和流程图只求看懂，最后落到一个 C 程序。"**

| 内容（按节号＝课本目录顺序） | 定位 | 讲法 / 时间 |
|---|---|---|
| §2.1 程序 = 算法 + 数据结构 | 点到 | Wirth 公式"算法+数据结构=程序"；算法是灵魂、数据结构是载体 |
| §2.2 什么是算法 | 点到 | 广义定义"解决问题的方法和步骤"；数值/非数值算法各一句 |
| §2.3 简单的算法举例 | ★引出循环 | **例 2.1** 求 5!：原始步骤太笨 → S1~S5 循环记法；顺带提例 2.2~2.5（含条件/循环，课后看） |
| §2.4 算法的 5 个特性 | ★必讲透(常考) | **有穷性、确定性、有零个或多个输入、有一个或多个输出、有效性**，各 1 句 + 1 反例，约 8 min |
| §2.5.1 用自然语言表示算法 | 带过 | "歧义"痛点（张先生/李先生的孩子），约 5 min |
| §2.5.2 用流程图表示算法 | 会认即可 | 认 **7 个符号**(图2.3：起止/输入输出/判断/处理/流程线/连接点/注释)，看懂**例 2.6** 求 5! 流程图（直到型），**不练手绘**，约 6 min |
| §2.5.3 三种基本结构和改进的流程图 | ★★本章唯一硬核 | BS"面条"问题 → **Bohra & Jacopini(1966)** 提出顺序/选择/循环，约 15 min |
| §2.5.4 用 N-S 流程图表示算法 | ★重点练(实用主力) | Nassi & Shneiderman(1973) 盒图；投 `li2.18_ns.svg` 认当型/直到型；**例 2.11** 求 5! 的 N-S，约 8 min |
| §2.5.5 用伪代码表示算法 | ★重点练(实用主力) | 拿**例 2.16** 求 5! 亲手写一遍伪代码(当型 while)，约 7 min |
| §2.5.6 用计算机语言表示算法 | ★落地收尾 | **只讲例 2.18**，把例 2.16 伪代码逐行翻成 C，接第 3 章，约 15 min |
| §2.6 结构化程序设计方法 | 点到 | **4 个方法**：自顶向下、逐步细化、模块化设计、结构化编码，一句话带过 |

**核心认知**：§2.5 的几种表示法不是并列知识，是一条"嫌上一个不好用才发明下一个"的**升级链**。日常真正常用的是**伪代码 + N-S 图**（课本自己也说"本书主要采用 N-S 图"）；流程图只求看懂；自然语言只是引子。

## 二、贯穿主线（别按小节讲，按"一道题的升级"讲）

全章死磕**求 5!** 一道题（教材本就如此，见"例题地图"）。每换一种表示法，先抛一句**"上一种哪里不爽？"**，让学生自己"想要"下一种：

> **例 2.1** 自然语言写 999 步太累 → **例 2.6** 流程图 → 箭头乱跳、一改重画 → **§2.5.3 规定只用三种基本结构** → 怎么把结构框死？ → **例 2.11** N-S 图 → 画图太麻烦 → **例 2.16** 伪代码 → 机器看不懂 → **例 2.18** C 程序

这样"重复"变成"升级"，每遍都有新动机，不灌水。**三种基本结构那一步是全章高潮，讲慢**——它直接对应第 3~5 章语法（顺序=语句、选择=if、循环=while/for）。

## 四、一次课（90 min）分钟级节奏表

| 时间 | 环节 | 动作 |
|---|---|---|
| 0–8 | 引入 | "算法+数据结构=程序"，算法是灵魂；抛求 5! |
| 8–20 | 概念+特性 | 例 2.1 讲稿：自然语言的痛 → S1~S5；算法 5 特性（**有效性**别漏） |
| 20–35 | 流程图+三结构 | 认 7 个符号(图2.3)、看懂例 2.6 流程图；**讲透顺序/选择/循环**(高潮) |
| 35–50 | N-S+伪代码 | 投 `li2.18_ns.svg`（例 2.11）；带学生写一遍例 2.16 伪代码 |
| 50–65 | C 落地 | 讲 `li2.18.c`（例 2.18），伪代码逐行→C；跑一遍得 120 |
| 65–75 | 结构化方法 | §2.6 四方法：自顶向下/逐步细化/模块化/结构化编码，一句话 |
| 75–90 | 收尾+习题 | 回扣升级链(例2.1→2.6→2.11→2.16→2.18)；布置习题 |

## 五、"一次课讲完一章"合适吗？——合适

- **合适**：本章无新语法负担、纯观念，按上面狠砍后 90 min 能走完，很多老师就是这么安排的。
- **两种情况建议拆成 2 次课**：① 学生基础弱、N-S/伪代码当堂练需要时间；② 想把例 2.2~2.5 也带做代码演示。拆法：第 1 次到"三种基本结构"，第 2 次"N-S+伪代码+例 2.18 源码"。
- **底线**：无论一次还是两次，**课上必讲的源码就例 2.18 一个**，其余全是参考——这正是"不死磕"的落点。

## 附、课本事实速查（应对学生提问，均已核对正文）

- **Wirth 公式**：算法 + 数据结构 = 程序（§2.1）。
- **算法 5 特性**：有穷性、确定性、有零个或多个输入、有一个或多个输出、**有效性**（§2.4）。
- **三种基本结构**：1966 年 **Bohra 和 Jacopini** 提出；无规律跳转的烂算法称 **BS 型（一碗面条 / a bowl of spaghetti）**（§2.5.3）。
- **N-S 盒图**：1973 年 **Nassi 和 Shneiderman** 提出，又称"盒图(box diagram)"，完全去掉带箭头的流程线（§2.5.4）。
- **课本自陈**：因国内初学者情况，"本书主要采用形象化的 **N-S 图** 表示算法"（§2.5.5 末）。
- **§2.6 结构化 4 方法**：自顶向下、逐步细化、模块化设计、结构化编码。
- **例 2.19**：把例 2.17 的多项式算法用 C 表示，`deno/sum/term` 用 **double**（浮点），是"写出程序≠实现算法，运行才是实现"的落点。

### 第 6 张 · §2.2 什么是算法
**【提词】**
- 开口就说："算法听着高深，其实广义说就是——解决一个问题的方法和步骤。"
- 关键词：① 方法和步骤 ② 同一题可有多种算法 ③ 要挑质量好的
- 回看钩子（易混点）：算法 ≠ 程序/代码——先把步子想清楚就已经是算法（挂回头 4 张那个公式）
- 问学生："从宿舍到食堂，是不是也有'算法'？谁的路最短，谁就是好算法。"
- 收："对同一个问题，算法不唯一，所以我们还要挑'又快又好'的。" → 翻页

**【口播】**
"那到底什么是算法？别想复杂。**广义地说，为解决一个问题而采取的方法和步骤，就叫算法**。你从宿舍走到食堂，先下楼还是先拐角，这也是个算法。关键有两点：**同一个问题可以有不同算法**（有的绕远有的抄近道），所以我们不光要'做出来'，还要挑'做得好'的算法。这句定义得跟前面那个公式挂上：算法只管'一步一步怎么做'，它不是程序、也不是代码——把'算法'当成'写出来的程序'，是这一章第一个易混点。"

### 第 12 张 · §2.4 算法的 5 个特性（上：有穷性·确定性）

### 第 13 张 · §2.4 算法的 5 个特性（下：输入·输出·有效性）

- 收："流程图清楚多了吧？但它有个大毛病——箭头能乱跳。" → 翻页

**【口播】**
"把求 5! 画成流程图：图里那个菱形不是新东西，就是上一张说的岔路口，进去一个问题、出来两条路。t 置 1，i 置 2；然后 t×i 放回 t、i 加 1；再判断 i>5 成不成立，不成立就回头继续乘，成立就输出 t。【互动停顿】注意一个细节：它是**先把这一圈做完，再问要不要停**——这叫'**直到型**'循环。流程图是清爽多了，可你发现没——**箭头想指哪指哪，一旦复杂，就乱成一团面条**。这个病先记下——课本图 2.10 那个求闰年的流程图就很乱，可指给学生看。"

### 第 19 张 · 第 3 站 · 结构一：顺序

### 第 20 张 · 第 3 站 · 结构二：选择

### 第 21 张 · 第 3 站 · 结构三：循环之「当型」（先问后做）
**【提词】**
- 开口就说："第三种最厉害——循环，同一批活反复干。先看'当型'：先问一句成不成立，成立才进圈。"
- 关键词：当型 while / 先判断、后执行 / 对应 while、for
- 回看钩子（难点·接 2.4 有穷性）：条件就是出口；每圈 i 加 1 才保证出得去，否则就是死循环
- 问学生："求 5! 里哪几句是'反复干'的活？"（t=t*i 和 i=i+1）
- 收："先问后做，这就是当型。" → 翻页

**【口播】**
"第三种：**循环结构**——有段活要反复干。它分两种，这是第一种**当型**：**先问后做**，条件成立才进循环干一圈，不干就出圈。对应 C 语言的 **while、for**。放求 5! 上，反复干的就是 t×i 和 i+1 那两句。这儿有个跟 2.4 连着的点：那个条件就是出口。回想有穷性那条——为什么这个循环出得去？因为每绕一圈 i 都加 1，它一路朝着条件去。写这种循环最怕条件永远不假，那就是死循环。"

### 第 22 张 · 第 3 站 · 结构三：循环之「直到型」（先做后问）
**【提词】**
- 开口就说："循环第二种'直到型'：不管三七二十一先干一圈，再问要不要停。"
- 关键词：直到型 do-while / 先执行、后判断 / 对应 do-while
- 问学生："刚才例 2.6 是先问还是先做？"（先做再问=直到型）
- 收："记住：先问的是当型，先做的是直到型。" → 翻页

**【口播】**
"循环第二种：**直到型**——**先做后问**，不管条件先干一圈，再看要不要继续，直到某条件成立才停。对应 C 语言的 **do-while**。【互动停顿】回想例 2.6，它就是先乘完再问 i>5，所以是直到型。一句话钉死：**先问的是当型，先做的是直到型**。到这儿，顺序、选择、循环三种基本结构全到齐了。"

### 第 29 张 · 第 6 站 · C 程序：例 2.18 源码带读 + 跑起来（本章唯一真程序）
**【提词】**
- 开口就说："终点站——把刚才那份伪代码，一行不差翻成能跑的 C。"
- 关键词：① int i,t; 先定义 ② t=1;i=2; 起点 ③ while(i<=5) 当型闸门 ④ t=t*i; i=i+1; 循环体 ⑤ printf 输出
- 问学生："i<=5 什么时候变假？变假了程序去执行哪句？"（跳出去 printf）
- 回看钩子（减压）：这段除了 while 全是第 1 章的老相识（#include、main、花括号、printf）
- 收："跑一下，屏幕蹦出 120——伪代码里的 while，落到 C 就是这一句 while，一字不差。" → 翻页

**【口播】**
"升级链最后一站，真程序。我把例 2.16 的伪代码逐行翻成 C：
```c
#include <stdio.h>
int main( )
{   int i, t;
    t = 1;              // 起点：t 置 1
    i = 2;             // 起点：i 置 2
    while(i <= 5)      // 当型闸门：i 不大于 5 就进循环
    {   t = t * i;     // 反复干：累乘
        i = i + 1;     // 反复干：i 加 1
    }
    printf("%d\n", t); // 出圈后：输出结果 120
    return 0;
}
```
点一下运行，屏幕蹦出 **120**，成了。【互动停顿】这一段除了 while，剩下的全是你第 1 章写过的老相识：#include、int main、那对花括号、printf；真程序里今天新增的就 while 一个词——恰好是三种结构里最难缠的那个，其余都白送。你看，**伪代码写 while，C 里就是 while；伪代码写 t*i⇒t，C 里就是 t=t*i**——几乎一一对应。这就是为什么前面要绕这么多站：把逻辑想清楚了，翻成任何语言都是体力活。"

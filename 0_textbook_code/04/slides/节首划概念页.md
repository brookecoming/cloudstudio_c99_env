## 页 3 ｜ §4.3　关系运算符和关系表达式
> **插在放映第 27 张（关系运算符那页）之前**

📖 **动笔划课本 · §4.3　关系运算符和关系表达式**
- P89 在 C 语言中，比较符（或称比较运算符）称为关系运算符。（§4.3）
- P89 所谓"关系运算"就是"比较运算"，将两个数值进行比较，判断其比较的结果是否符合给定的条件。（§4.3）
- P90 C 语言提供 6 种关系运算符：< <= > >= == !=（§4.3.1）
- P90 前 4 种关系运算符的优先级别相同，后 2 种也相同。前 4 种高于后 2 种。（§4.3.1，图 4.5）
- P90 用关系运算符将两个数值或数值表达式连接起来的式子，称为关系表达式。（§4.3.2）
- P90 关系表达式的值是一个逻辑值，即"真"或"假"。在 C 的逻辑运算中，以"1"代表"真"，以"0"代表"假"。（§4.3.2）

【重点】6 种关系运算符；关系表达式的值是 1 / 0　【难点】优先级：算术 > 关系 > 赋值　【易错易混】判等用 `==`（两个等号），单个 `=` 是赋值；值是 1/0 不是 true/false

## 页 4 ｜ §4.4　逻辑运算符和逻辑表达式
> **插在放映第 37 张（§4.4 节标题页）之前**

📖 **动笔划课本 · §4.4　逻辑运算符和逻辑表达式**
- P90 有时要求判断的条件不是一个简单的条件，而是由几个给定简单条件组成的复合条件。（§4.4）
- P91 用逻辑运算符将关系表达式或其他逻辑量连接起来的式子就是逻辑表达式。（§4.4）
- P91 有 3 种逻辑运算符：与(AND)、或(OR)、非(NOT)。在 C 语言中用 &&、||、! 代替，见表 4.1。（§4.4.1）
- P91 "&&"和"||"是双目(元)运算符，它要求有两个运算对象(操作数)；"!"是一目(元)运算符，只要求有一个运算对象。（§4.4.1）
- P92 逻辑运算符的优先次序：!(非) → &&(与) → ||(或)。（§4.4.1）
- P93 在逻辑表达式的求解中，并不是所有的逻辑运算符都被执行，只是在必须执行下一个逻辑运算符才能求出表达式的解时，才执行该运算符。（§4.4.2 短路）

【重点】`&&`、`||`、`!` 三种逻辑运算符；逻辑表达式值为 1/0　【难点】短路求值：`&&` 前假则不算后、`||` 前真则不算后　【易错易混】`&&` 别写成按位 `&`；`!` 优先级最高；闰年式的括号不能省

## 页 5 ｜ §4.5　条件运算符和条件表达式
> **插在放映第 51 张（§4.5 节标题页）之前**

📖 **动笔划课本 · §4.5　条件运算符和条件表达式**
- P94 有一种 if 语句，当被判别的表达式的值为"真"或"假"时，都执行一个赋值语句且向同一个变量赋值。（§4.5）
- P94 赋值号右侧的"(a>b)? a:b"是一个"条件表达式"。"?"是条件运算符。（§4.5）
- P94 条件运算符由两个符号(? 和:)组成，必须一起使用。要求有 3 个操作对象，称为三目(元)运算符，它是 C 语言中唯一的一个三目运算符。（§4.5）
- P94 条件表达式的一般形式为：表达式1 ? 表达式2 : 表达式3（§4.5）
- P96 ch=(ch>='A' && ch<='Z') ? (ch+32) : ch;（§4.5 例 4.4）

【重点】条件表达式 `表达式1?表达式2:表达式3`；唯一三目运算符　【难点】`?:` 与关系/算术运算符结合时的括号　【易错易混】32 是大小写字母的 ASCII 差；`?:` 优先级低于关系/算术运算符

> **插在放映第 63 张（§4.6 节标题页）之前**

📖 **动笔划课本 · §4.6　选择结构的嵌套**
- P96 在 if 语句中又包含一个或多个 if 语句称为 if 语句的嵌套(nest)。（§4.6）

## 页 7 ｜ §4.7　用 switch 语句实现多分支选择结构
> **插在放映第 73 张（§4.7 节标题页）之前**

📖 **动笔划课本 · §4.7　用 switch 语句实现多分支选择结构**
- P99 if 语句只有两个分支可供选择，而实际问题中常常需要用到多分支的选择。（§4.7）
- P99 但如果分支较多，则嵌套的 if 语句层数多，程序冗长而且可读性降低。C 语言提供 switch 语句直接处理多分支选择。（§4.7）
- P99 switch 语句是多分支选择语句。（§4.7）
- P99 case 'A': printf("85~100\n");break; … default: printf("enter data error!\n");（§4.7 例 4.6）

【重点】switch 多分支；case + break；default 兜底　【难点】case 穿透（fall-through）的机制　【易错易混】每个 case 末尾漏 `break` 会穿透到下一个 case

## 五、例题怎么讲（含一次讲不完怎么拆）

### ① 每个例题都套同一套"四步讲法"（正好回指主线）
拿到任何一个 例3.x，都按这四步张嘴讲，学生永远知道"现在在流水线的第几步"：
1. **这题要干什么**——一句话念题干结论；
2. **数据装什么盒子**——用了哪些变量、什么类型（回指 §3.2）；
3. **怎么算**——关键那行表达式/赋值（回指 §3.3/§3.4，强调"先算右边再赋左边"）；
4. **怎么进出**——scanf 读入 / printf 用什么格式符（回指 §3.5）。
> 每个 `li3.x.c` 源码末尾已附【六拍讲解过程稿】，照着念即可，不必临场组织语言。

### ② 9 个例题分三档，别平均用力
| 档 | 例题 | 课上怎么处理 |
|---|---|---|
| **精讲（4 个，撑主线）** | 例3.1 跑通第一个程序 / 例3.3 大小写(字符ASCII) / 例3.5 求根(scanf) / 例3.7 float精度(printf) | 四步讲法全走 + 上机跑一遍，各 8~12 min |
| **带过（3 个，同类不重复）** | 例3.2 存款(同3.1) / 例3.4 三角形(同3.5类) / 例3.6 %f默认6位(并入3.7讲) | 只点"比上一个多了什么"，各 2~3 min |
| **课后参考（2 个）** | 例3.8 putchar / 例3.9 getchar | 字符 IO 次要，布置自习，课上不展开 |

### ③ 本章已定排两次课（每次 90 分钟）——按主线拦腰拆
90 min 硬塞 9 个例题＋100 多页必然赶，故按主线拆成两次：
| 次 | 覆盖节 | 精讲例题 | 课堂收尾 |
|---|---|---|---|
| **第 1 次：看懂程序＋选对类型** | §3.1 举例 + §3.2 数据类型 | 例3.1、例3.3 | 学生手写一个“定义+赋值+printf”小程序 |
| **第 2 次：算对＋赋值＋输入输出** | §3.3 运算符 + §3.4 赋值 + §3.5 输入输出 | 例3.5、例3.7 | 上机跑例3.5(scanf)＋例3.7(看精度) |

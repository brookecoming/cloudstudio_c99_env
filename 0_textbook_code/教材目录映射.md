## 三、使用说明（Agent 红线）

1. **定位课本原文**：先查本文件找到节号对应的图片路径 → 用 `Read` 工具打开 JPG → 照抄原句。绝不凭记忆编造页码或章名。
2. **判断某知识点属于哪一章**：在本文件搜索关键词（如"指针"、"结构体"、"编译预处理"），一步定位。
3. **编译预处理不是独立章**：第五版中 `#define`/`#include`/条件编译散布在第 7 章函数（§7.11 附近）及各章习题说明中，无独立章节。

5. **页码校验公式**：`图片文件 p{N}.jpg` 的 N 就是课本印刷页码；PDF 工具页码 = N + 24。
